# 🏔️ Hill Climb 3D Pro: Infinite Extreme Off-Road

An interactive, high-performance 3D procedural off-road racing game built with **Three.js**, **Tailwind CSS**, and the **Web Audio API**. Designed for both mobile smartphones and desktop browsers.

---

## 🚀 Features

* **📱 Mobile Screen Rotation**: One-click screen rotation button that toggles between Portrait and Landscape modes (works natively via Screen Orientation API and through instant CSS transformation on iOS Safari/Android).
* **♾️ Infinite Procedural Map**: Endless rolling mountains and extreme high-altitude climbs generated in real time without lag or boundaries.
* **⛰️ Extreme High Hills & Stunt Bridges**: Towering peaks up to 35m high, cliff-side drops, wooden suspension jump ramps, and canyon gap crossings.
* **⛅ Dynamic Weather Cycle**: Real-time atmospheric conditions:
  * ☀️ **Sunny Dunes** (Warm golden daylight)
  * 🌧️ **Mountain Rain** (Rain streaks, wet surface reflections, distant thunder flashes)
  * ❄️ **Snow Blizzard** (Chilly icy blue fog with drifting snowflakes)
  * 🏜️ **Sunset Sandstorm** (Orange desert haze with flying dust particles)
* **⛽ Full Fuel Canisters & Refueling**: Collectible 3D Jerrycans that fully recharge your fuel tank with a green flare animation and audio chime.
* **🚗 3 Unique 3D Vehicles**:
  1. *Crawler 4x4 (Classic Jeep)* — Balanced torque and suspension rig.
  2. *Dune Buggy* — Ultra lightweight for rapid air flips.
  3. *Monster Crusher* — Giant knobby tires for climbing 50° inclines.
* **🧰 Custom Garage & Upgrades**:
  * Upgrade V8 Engine Torque, High-Altitude Suspension, Rock Tires, and Nitro Superchargers.
  * 6 metallic paint swatches with real-time material reflections.
  * LocalStorage auto-save for all stats, coins, and unlocks.
* **🔊 Synthesized Web Audio Engine**: Zero external audio files required! Procedural V8 engine rumble, turbo whistle, coin chime, and stunt fanfares.

## 🎮 Controls

### Desktop Keyboard
| Key | Action |
| :--- | :--- |
| **W / Up Arrow** | Gas / Accelerate / Counter-Clockwise Air Flip |
| **S / Down Arrow**| Brake / Reverse / Clockwise Air Flip |
| **A / Left Arrow** | Steer Left |
| **D / Right Arrow**| Steer Right |
| **Shift** | Nitro Boost |
| **Spacebar** | Hydraulic Hop |
| **C** | Cycle Camera (Side Cam, Chase Cam, Hood Cam) |
| **L** | Toggle Headlights |
| **ESC / P** | Pause Menu |

### Mobile Touch
* **Gas & Brake Pedals**: Touch-sensitive pedals with active 3D press depression.
* **Hop & Nitro Buttons**: Instant fingertip triggers.
* **Rotate Button**: Switch between portrait and landscape layouts with one tap.
